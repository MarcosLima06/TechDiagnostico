
# TechDiagnóstico — Central de Diagnóstico de TI

## Objetivo
Desenvolver uma aplicação web para auxiliar profissionais de suporte técnico na análise básica de computadores e redes, além de permitir o registro de atendimentos técnicos.

## Funcionalidades
- Identificação do sistema operacional
- Verificação da conexão de rede
- Diagnóstico de DNS
- Monitoramento da memória RAM
- Análise do uso do processador (CPU)
- Verificação do armazenamento
- Consulta dos processos em execução
- Verificação dos serviços do Windows
- Consulta do tempo de atividade do computador
- Identificação das interfaces de rede local
- Registro de atendimentos técnicos
- Geração de relatório técnico com protocolo
- Exportação do relatório em PDF

## Tecnologias utilizadas
- Python
- Flask
- Psutil
- HTML5
- CSS3
- JavaScript

## Como executar o projeto

1. Instale o Python.
2. Abra a pasta do projeto no terminal.
3. Instale as dependências:

   pip install flask psutil

4. Inicie o servidor:

   python app.py

5. Acesse no navegador:

   http://127.0.0.1:5000

## Observações
O sistema foi desenvolvido para execução local em ambiente Windows. Os diagnósticos são realizados no computador em que o servidor Flask está sendo executado.

## Finalidade
Projeto prático desenvolvido para aprimorar conhecimentos em desenvolvimento web, Python e suporte técnico de TI.
